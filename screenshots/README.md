# Screenshot checklist

Save genuine images captured from your own run in this folder. Suggested captures:

1. Dashboard with live measurements and chart.
2. `/docs` showing the ingestion API and validation.
3. Low-moisture alert and automatic watering history.
4. Manual water control and changed threshold.
5. Offline status and its alert after waiting for the heartbeat timeout.
6. Actual automated test output after `python -m pytest`.
7. Cloud deployment console and public URL only after a real deployment.

Do not include API keys, `.env` values, credentials or private URLs in screenshots. Cloud, GitHub and physical hardware images must reflect real completed work.
